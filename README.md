# Overslime

# What is it about?
Overslime is a 2D sidescroller, rogue-like game where you play as a slime and
have to defend your home from adventurers

# How to Play?
Movement - AS or Left and Right Arrow Keys
Jump - W or Space
Down slam - S (NOT YET ADDED)
Attack - Right Click (NOT YET ADDED)
